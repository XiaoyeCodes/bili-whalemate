# 小时额度升级说明

## 变更

小时读写预算从首次请求开始的 60 分钟窗口调整为北京时间整点小时。每日预算固定在北京时间零点重置，不再取决于服务所在机器的时区。额度耗尽时的 `retryAt` 与计数使用同一个恢复时间。

`traffic-state.json` 中同一整点小时内的已有计数保留，过期小时读取为零；每天累计和已提交、待核查的操作记录保留，不需要删除或手工归零。升级时原有窗口中属于上一整点小时的计数会过期。

## 迁移

1. 同时更新 `vendor/bili-whale/tools/lib/traffic.mjs`、记忆服务的 `service/bili_write_usage.py`、`service/server.py` 和设置页 `client.js`。本组合包已包含这些文件。
2. 重启记忆服务并刷新设置页。每次新启动的 CLI 进程会读取新的请求保护逻辑，已有长驻 CLI 进程需要重启。
3. 确认“本小时”显示北京时间整点范围、已保存的上限及剩余次数，下一整点后小时用量自动归零。每日用量仍累计到零点；读取页面或用量接口不会清空计数。
