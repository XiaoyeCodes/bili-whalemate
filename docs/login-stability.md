# 登录状态与后台检查

本机凭据与平台登录状态分开保存。会话验证只在平台明确返回未登录时标记失效；读取预算耗尽、限流、超时及其它无法确认的响应显示“凭据已保存，暂时无法验证”，不会清除凭据或要求反复扫码。

同一组凭据成功验证后缓存十分钟；临时失败至少等待一分钟，读取预算需要更久恢复时按其恢复时间等待。验证记录包含凭据摘要及状态，不包含 Cookie 或续期令牌。更换凭据后独立验证，不沿用另一组凭据的成功状态。

扫码与手动保存均使用同步写入、临时文件原子替换及私有备份。之后扫码返回的续期令牌与会话到期时间保存在本机凭据中，不返回页面。保存续期元数据不代表已实现自动续期；平台撤销会话、密码变更或安全验证仍可能需要本人重新登录。

后台轮询根据配置的每小时、每日读取额度计算实际间隔，并预留三分之一额度给登录验证、浏览、回读及额外分页。私信按每次至少一个读取请求、评论通知按两类各两页估算；实际间隔显示在自动活动状态中。配置的十五秒与默认每日三千次读取额度不能同时支持全天持续运行，系统不会通过清空计数绕过额度。
