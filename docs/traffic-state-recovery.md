# 请求保护记录与扫码验证

`traffic-state.json` 保存账号计数和已提交、待核查的请求。扫码保存凭据后，账号验证也经过同一请求保护；记录损坏会阻止验证，不代表扫码失败或凭据失效。

每次状态更新先同步写入 `traffic-state.json.bak`，再同步写入主文件；两份均使用临时文件、`fsync` 与原子替换。请求预留完成前不会发送网络请求。主文件损坏或丢失时使用有效备份，保留预算与未知发送记录；两份都无法读取时停止请求，不重置计数。

没有有效备份时，先保留损坏原件。人工建立只读恢复状态需设置 `recovery.writesPaused: true`；账号验证和读取可以恢复，写操作报告 `state-recovery`，普通登录恢复命令不会解除该暂停。发送记录无法还原时，不把旧操作标为未发送，也不自动重发；只有完成相应核查后才能恢复写入。
