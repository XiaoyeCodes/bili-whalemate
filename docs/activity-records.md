# 浏览、执行和报错记录

自动活动面板底部依次提供“最近浏览记录”“最近执行记录”“报错记录”，均使用可通过鼠标或键盘操作的原生折叠控件。浏览记录包含最近预览的摘要、推荐及评论草稿，以及最近十二次成功浏览；无记录时显示空状态。

自动任务的当前异常、历史失败、配图警告和发送结果不明的详情集中在报错记录中，执行记录仅保留状态、结果及打开报错记录的入口。设置保存、用量读取和浏览测试的错误也显示在同一控件内；用户主动保存失败时会展开该控件，正常的后台报错不会强制展开。

错误按通道记录出现、重复和解除状态，保存在现有 SQLite metadata 中；保留最近一百条通道记录，并合并最近一百条动作中的失败、警告和待核查结果。已经解除的故障不再计入当前异常，历史仍可查看。无法确认是否成功的发送继续标为待核查，不能因为新操作成功就自动重发或改成成功。

评论通知发生读取失败后，后续读取成功即解除该读取提示，和其它阶段的失败分开处理。读取预算错误按当前账号、上海日期和整点小时的剩余额度判断恢复；页面每次刷新状态时检查本地计数，不额外请求 B 站。不知道是否恢复的其它错误仍等待相应操作成功或人工核查，不按固定时间强行清空。
