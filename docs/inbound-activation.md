# 服务开启后的新消息

私信、主人评论和陌生人 @／评论回复分别记录本次启用时间。每次记忆服务启动、B 站总开关或自动活动从关闭变为开启，以及相应回复功能重新开启时，建立新的接收起点；普通保存设置不改变起点。

只回复平台时间晚于对应起点的消息。旧私信的 pending、queue 和新拉取的历史都会过滤；旧评论通知和重启前等待重试的草稿不会补发。服务启动到第一次轮询之间收到的新消息仍可处理。B 站消息时间精度为秒，起点所在秒的消息保守跳过。

成功及结果不明的发送记录保留，结果不明的操作不会因恢复或重启自动重发。回复等待写入间隔结束后会再检查开关和接收起点；关闭或重新启用功能会使旧回复失效。

私信游标采用同步写入、临时文件原子替换及 `.bak` 副本。主文件无法解析时读取有效备份；两份都损坏则停止处理，保留数据等待恢复，不把游标清空后回放历史。
