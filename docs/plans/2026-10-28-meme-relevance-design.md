# 表情包描述与场景匹配

用户需要准确配字、画面描述和情绪分类，并要求自动回复与当前问题相符。

这批 400 张新增图片逐张对照原图修订；看不清的长段文字只描述画面，不猜写台词。情绪使用现有六类，具体用途写在关键词中。明显带成人暗示、辱骂或威胁的图保留在图库，关键词标明“自动回复禁用”。图片文件和图库归属保持原值。

只修关键词仍会让同情绪的无关图片混在一起。仅做词语排序也不能判断安慰、嘲讽等语气是否适合。采用两步匹配：复用现有中文分词按具体场景召回，再用已配置的对话模型核对最新问题、拟回复和候选描述，最多批准一张。

图库浏览继续使用 `/memes`；自动回复改用 `POST /memes/search`，对话内容放 JSON 请求体。缺少问题、只有宽泛情绪、没有场景命中、模型不可用、判断结果无效或不合语境时均不配图。模型选中的文件必须来自本次候选，不随机兜底。

`find_meme` 需要 `q` 和 `context`，输出配字、关键词、完整路径和匹配理由。其请求超时由 `memeMatchTimeoutMs` 控制。验证覆盖场景排序、情绪过滤、禁用标记、无关问题、判断失败及实际图库的问候、安慰和技术问题。
