# 表情包自动配图修复

100% 在每条真实用户回复后尝试选图，普通聊天可以使用经过语境核对的通用反应图；严肃内容、禁用图片、平台禁图和发送额度仍可阻止发送。低于 100% 仍按同一概率抽取机会。

1. 扩展共享召回，把具体话题候选与通用聊天反应交替提供给判断模型；不直接随机发送。QQ、网页和 B 站使用相同规则。
2. QQ 记录选图、跳过和发送失败的结果；未确认发送不自动重传图片。
3. 网页通过独立插件记录和聊天节点显示自动配图；记录可回放，恢复会话不重发。新用户消息使旧回复的延迟配图失效。
4. 设置页显示最近配图结果和 B 站额度提示；不修改 B 站发送预算。
5. 验证通用聊天召回、100%/0% 端点、禁用项、过期回复、失败保留正文、网页记录回放及实际图片加载。外部消息发送不用于自动验收。
