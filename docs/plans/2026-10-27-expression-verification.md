# 表情发送链路验证

检查现有设置的实际作用，不把模型提示频率宣称为精确随机概率。QQ 沿用当前官方机器人的图片工具；B 站沿用现有纯文本评论和私信，不增加图片发送接口。

修复旧 QQ 工具名与当前 qqbot_send_file 不一致的问题，规范 Windows 图库路径，仅为图库增加受限路径白名单。让 B 站文本草稿读取同一组颜文字和 emoji 设置。用离线插件钩子测试 0%、20%、50%、100% 的模型提示、真实文件路径与工具参数；用实际 QQ 会话检索并发送图库图片，再验证 B 站文本生成和有限私信发送，最后还原用户原频率。

图库按情绪及关键词检索后，由模型决定发送合适图片，不定时轮播；百分比为近似使用频率，短样本不用于证明精确概率。
